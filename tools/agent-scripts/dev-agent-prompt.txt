3. HARD RULES (breaking these breaks the build or the owner's trust)
======================================================================

- **Never reference a GDScript class by its class_name.** preload() the script by path instead. Godot resolves class_name through a cache that only an editor run builds, so on a fresh clone the reference fails to parse.
- **Fresh-clone check before every PR:**
  `rm -rf $TMPDIR/pf-fresh && git clone -q . $TMPDIR/pf-fresh && godot --headless --path $TMPDIR/pf-fresh --quit 2>&1 | grep -E "SCRIPT ERROR|Failed to load script"`
  ANY output means it failed, whatever the exit code; the exit code is 0 either way.
- **tools/scenario_runner.gd is APPEND-ONLY,** because three agents edit it in parallel:
  - Add the new scenario name at the END of SCENARIO_NAMES.
  - Add exactly one match arm immediately before the `\t\t_:` arm.
  - Put the new scenario functions at the END of the file.
  - Scenarios must free every node they create.
  - Every new scenario must fail on the old code. Prove it red first (TDD).
- **Full suite** must pass before a PR (see the runner header for the exact invocation):
  `perl -e 'alarm 1500; exec @ARGV' godot --headless --path . --script tools/scenario_runner.gd -- --all`
  The baseline is about 640 passing.
- **Time limits:** macOS has no `timeout` binary. Wrap every Godot run in `perl -e 'alarm N; exec @ARGV' ...`.
- **Windows:** you may open windowed Godot (e.g. to screenshot UI work), but one at a time, in the foreground, under a perl alarm. Afterwards confirm with `pgrep -fl godot` that it exited, and kill it if not. NEVER leave a window open or background a run without a time limit; an earlier run left ~100 windows open. The suite and fresh-clone check always run --headless.
- **Features doc:** any PR that adds, removes or changes a player-facing feature updates docs/FEATURES.md in the same PR.
- **Input scheme** is settled by ADR-0003. Never reopen it.
- **The repo is PUBLIC.**
  - Never commit, paste or echo secrets, tokens, API keys or PATs, in code, issues, PR bodies or logs.
  - Never bypass or disable the pre-commit secret-scrub hook.
- **Owner-only:** no deploys, no Fly.io/relay deploys, no itch/butler uploads, no Steam or store submissions, no tags or releases.
- **Git:**
  - Never run a bare `git stash`; a pre-existing stash must survive.
  - Never force-push main.
  - Never push to a branch you didn't create.
  - Never rewrite or close other people's PRs.
- **Commits** end with:
  `Co-Authored-By: Claude <noreply@anthropic.com>`
- **PR bodies** end with:
  `🤖 Generated with [Claude Code](https://claude.com/claude-code)`

5. PER-TICKET LOOP
======================================================================

1. `git fetch origin`, then create the worktree:
   - `git worktree add -b fix/issue-<n>-<slug> .claude/worktrees/<n>/pickfight origin/main`
   - Then `godot --headless --path .claude/worktrees/<n>/pickfight --import`
2. `/atlas-implement <n>`. The ticket's line numbers may be stale, so locate code by function name. Write a failing scenario first, then fix.
3. Verify yourself; don't trust the worker's report alone:
   - full suite
   - fresh-clone check
   - read the diff
4. Push the branch and open the PR:
   - `gh pr create --base main --head fix/issue-<n>-<slug> --title "fix: <summary> (#<n>)" --body ...`
   - The body says what was wrong and why, what changed, the scenarios added (and that they failed before the fix), the suite pass count, and that the fresh-clone check is clean.
   - The body includes "Closes #<n>" and ends with the attribution line.
5. `gh pr checks <pr> --watch`.
   - If CI is red, fix it and push.
   - If main moved and the PR conflicts, merge origin/main in, keep both sides (scenario_runner conflicts are always "keep both"), re-run the suite and push.
6. **Don't merge your own PR.** The tkneeland integrator merges green PRs. Comment "CI green, ready to merge" and move on.
   - If the PR is still unmerged 2 hours after going green, comment once to bump it, then keep working.
7. After it merges, remove the worktree and delete the local branch.
