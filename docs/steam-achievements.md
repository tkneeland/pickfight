# Steam achievements (#689)

The 18 achievements the game reports to Steam. Names and descriptions are the English strings in `translations/strings.csv` (keys `ACH_<ID>_NAME` and `ACH_<ID>_DESC`); enter the same text, and the translations, in the Steamworks partner site. None is hidden.

Earned by any human seat: an event of a human player credits the host PC, and a PC client in that seat is told to unlock it on its own account. Bots never credit. Solo counts everything except Untouchable and Last Life.
